# Infra Lifecycle

It's a number of clearly defined and distinct work phases, used by DevOps engineers,
to plan, design, build, test, deliver, maintain and retire cloud infra.

## day 0, day 1 and day 2?

day 0-2 is a simplified way to describe phases of an infra lifecycle.

- day 0 is the planning and designing phase.
- day 1 is the developing and iterating phase.
- day 2 is, go live and maintain phase.

### how IaC enhances IL?

- reliability: makes changes idempotent, consistent, repeatable and predictable.

> idempotent: don't matter how many times you run IaC, you will always get the same result

- manageability: enables mutation via code. revised, with minimal changes.
- sensibility: avoids issues when important institutions depend on infra
